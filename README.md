# 🍜 FoodTI - 食物人格测试

**测测你的食物人格是什么？四个维度，解码你的美食DNA。**

## 🎯 项目简介

FoodTI 是一个趣味性食物人格测试，通过 18 道关于食物偏好、饮食习惯和用餐行为的问题，将用户归类为 8 种食物人格类型之一。

## 🧩 四个维度

| 维度 | 两端 | 说明 |
|------|------|------|
| 维度一 | 冒险度 vs 安全感 | 面对未知食物的态度 |
| 维度二 | 过程型 vs 结果型 | 享受烹饪过程还是追求成品 |
| 维度三 | 独享型 vs 共享型 | 独自享用还是与人分享 |
| 维度四 | 直觉型 vs 分析型 | 凭感觉还是理性决策 |

## 🏆 8 种食物人格

| 类型 | 英文名 | 特征 |
|------|--------|------|
| 🧭 美食探险家 | Food Explorer | 冒险 + 过程 + 共享 + 直觉 |
| 🧮 营养计算器 | Calorie Counter | 安全 + 结果 + 独享 + 分析 |
| 🎉 社交食客 | Social Eater | 冒险 + 结果 + 共享 + 分析 |
| 🍵 慢食享受家 | Slow Foodie | 安全 + 过程 + 独享 + 直觉 |
| 🦅 独行美食家 | Lone Gourmet | 冒险 + 过程 + 独享 + 分析 |
| 🌾 随缘干饭人 | Casual Diner | 安全 + 结果 + 共享 + 直觉 |
| ⚡ 即食效率派 | Fast Fuel | 冒险 + 结果 + 独享 + 分析 |
| 🏠 温暖家常派 | Home Cook | 安全 + 过程 + 共享 + 直觉 |

## 🛠️ 技术栈

- **HTML5** - 语义化结构
- **CSS3** - 暖橙色系卡片式设计，移动端适配
- **JavaScript (ES6+)** - 原生实现，无框架依赖
- **Chart.js** - 雷达图可视化

## 🚀 部署

### GitHub Pages

1. Fork 本仓库
2. 进入 Settings → Pages
3. 选择 `main` 分支，根目录 `/`
4. 访问 `https://<username>.github.io/foodti/`

### Vercel

1. 导入 GitHub 仓库
2. 无需任何构建配置
3. 自动部署

### Netlify

1. 导入 GitHub 仓库
2. 发布目录设为根目录
3. 部署
