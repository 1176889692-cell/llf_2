# FoodTI 食物人格测试

通过20道精选题目，解码你的美食DNA，发现你的食物人格类型。

## 🎯 特性

- **40+题库** - 每次随机抽取20道题，保证新鲜感
- **四维度分析** - 冒险度/过程型/共享型/直觉型
- **8种人格类型** - 精准匹配你的食物人格
- **雷达图可视化** - 直观展示你的维度分布
- **分享功能** - 支持微信/微博/复制分享
- **精美UI** - 暖橙色系，温暖食欲风格

## 🚀 在线体验

访问地址：https://你的用户名.github.io/foodti-test/


## 🎨 食物人格类型

| 类型 | 英文名 | 特点 |
|------|--------|------|
| 🧭 美食探险家 | Food Explorer | 勇于尝试，创意烹饪 |
| 🧮 营养计算器 | Calorie Counter | 理性选择，注重健康 |
| 🎉 社交食客 | Social Eater | 社交达人，氛围营造 |
| 🍵 慢食享受家 | Slow Foodie | 享受过程，品味细腻 |
| 🎭 独行美食家 | Lone Gourmet | 独立自主，标准独特 |
| 🌾 随缘干饭人 | Casual Diner | 随遇而安，容易满足 |
| ⚡ 即食效率派 | Fast Fuel | 效率至上，结果导向 |
| 🏠 温暖家常派 | Home Cook | 热爱烹饪，温馨治愈 |

## 📊 四个维度

1. **冒险度 vs 安全感** - 你对新食物的接受程度
2. **过程型 vs 结果型** - 你更享受烹饪过程还是美味结果
3. **共享型 vs 独享型** - 你喜欢分享还是独自享用
4. **直觉型 vs 分析型** - 你如何做出食物决策
